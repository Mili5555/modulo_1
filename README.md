# modulo_1
### Selección y Evaluación de Factibilidad del Trabajo Final de Carrera

En este trabajo se realizó un análisis comparativo de tres alternativas de proyectos industriales: producción de aceite de semillas de uva, desarrollo de bioplásticos agroindustriales y reciclaje de plásticos PET.

Para ello, se utilizó Gemini Notebook como herramienta de investigación, recopilando y analizando información técnica, científica y normativa. A través de una matriz de decisión ponderada, se evaluaron aspectos como la viabilidad técnica, disponibilidad de información, innovación y factibilidad temporal.

**El objetivo fue seleccionar la alternativa más adecuada para desarrollar el Trabajo Final de Carrera de Ingeniería Industrial**, fundamentando la elección mediante criterios objetivos.

Como resultado, se seleccionó la **producción de aceite y harina de semillas de uva**, elaborando un anteproyecto que contempla sus objetivos, alcance, metodología y cronograma de trabajo, bajo un enfoque de economía circular y aprovechamiento de subproductos vitivinícolas.
